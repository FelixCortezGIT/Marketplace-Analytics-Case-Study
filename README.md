# Marketplace Analytics Case Study

Business-oriented ecommerce analytics project focused on marketplace performance, KPI reporting, profitability analysis, and operational insights across multiple sales channels.

The project simulates an internal reporting workflow used to analyze transactional sales data from platforms such as Amazon, Allegro, and Kaufland using Python, data cleaning techniques, and dashboard visualization.

## Key Areas

- Data cleaning & preprocessing
- Marketplace performance analysis
- KPI reporting
- Profitability monitoring
- Country and category analysis

- Dashboard visualization

## Tech Stack

Python, Pandas, NumPy, Matplotlib, HTML, CSS
